# Навыки n8n — выжимка для резюме

## Одной строкой (шапка / заголовок)

> Автоматизация бизнес-процессов и AI-агенты на n8n: интеграции по API, вебхуки, LLM-агенты с инструментами, RAG-архитектура (векторные базы, эмбеддинги).

---

## Блок «Навыки» (списком в резюме)

- **n8n** — построение воркфлоу: триггеры, ноды, работа с данными (JSON, items, выражения `{{ }}`), просмотр и отладка executions
- **Интеграции по API** — нода HTTP Request, работа с любым REST API, подключение сервисов через Credentials (Google, Telegram, OpenAI и др.)
- **Логика процессов** — ветвление и маршрутизация (IF, Switch), объединение и циклы (Merge, Loop)
- **Вебхуки** — запуск воркфлоу извне, приём данных с сайтов и сторонних сервисов, публичные адреса через ngrok
- **AI-агенты** — LLM/Chat Model ноды, AI Agent с инструментами (tools), память диалога (Simple Memory), проектирование системных промптов и защита от галлюцинаций
- **RAG** — векторная БД Qdrant (Docker), эмбеддинги OpenAI (`text-embedding-3-small`), разбивка документов на чанки, семантический поиск по базе знаний, генерация ответов строго по данным клиента
- **Инфраструктура** — запуск n8n локально и в Docker, переменные окружения (`WEBHOOK_URL`), публикация чат-виджета на сайт

---

## Проект для портфолио

**AI-консультант по базе знаний (RAG)**

> Реализовал чат-бота поддержки, отвечающего строго по документам компании. Архитектура RAG: пайплайн индексации документов в векторную БД Qdrant (разбивка на чанки, эмбеддинги text-embedding-3-small) и пайплайн ответа на базе AI Agent с инструментом семантического поиска. Настроил защиту от галлюцинаций через системный промпт, память диалога и встраиваемый чат-виджет на сайт клиента.
>
> **Стек:** n8n, Qdrant (Docker), OpenAI, ngrok.
